# 原速闭环state驱动的LIBERO数据重构

2026-10-24。沿用严格IPOPT/B10、原生LIBERO物理、20Hz、原夹爪和原始时长。优化目标为同一时刻实际物理state接近原示范，并完成任务。本轮没有修改共享控制器或安装新依赖。

**后续用户约束修正：** 不跟踪原示范机器人关节轨迹，默认IPOPT必须原样执行。下文含关节跟踪的代价及60次/0.5秒适配层预算均保留为历史实验，不作为后续正式配置；新方案见`TASK_POSE_DEFAULT_IPOPT_METHOD.md`。库默认预算实际为20次/0.095秒；“源码未改”不等于“适配层采用库默认数值配置”。

## 文献与实际实现的对应

- [IRLC，IROS2024](https://lup.lub.lu.se/search/files/206302733/IROS24.pdf)、[接触示范修正，2026预印本](https://arxiv.org/html/2604.16850v1)：根据上一次实际执行误差更新控制参考。本文实现是带平滑、限幅、可达投影和完整state验收的工程适配，不声称复现原论文所有更新项或继承其收敛证明。
- [PhysicsGen，RSS2025](https://arxiv.org/html/2502.20382v2)：示范初始化、物理前向执行、机器人/物体state代价和CEM优化。
- [MuJoCo Predictive Sampling](https://arxiv.org/html/2212.00541)：少量参考节点表示、采样扰动并按真实rollout代价选择。没有引入Drake/MJX替换LIBERO，也没有用直接ctrl或源关节回放代替IPOPT。

## 固定流程

1. 以原速全局动作意图投影＋0.01下一state构型正则的原有11条录制作初始化。
2. 全部11条统一执行两轮IRLC式参考修正：增益依次0.5、0.25，误差提前一格（50ms），五点二阶Savitzky–Golay平滑。平移单次修正范数最多5mm、旋转最多0.03rad，以SO(3)左复合。
3. 每轮用上一可达参考的关节见证作投影初值及小正则，获得新目标FK；只将目标差分动作送入共享在线IPOPT。零修正应保持上一参考，避免反复往原state目标收缩。
4. 每个候选从相同源初始条件完整重录，没有逐帧强制恢复state；没有在源state上逐个拟合一步再拼接结果。只有全段可执行、已有任务成功不丢失且完整state代价严格下降才接纳，否则保留上一版本。
5. 对两个诊断样本再做同参数小规模CEM：Long00/demo_10（原失败）及Goal02/demo_1（原成功但state误差偏大）。CEM没有在全部11条运行，因此不把本轮结果称为全任务CEM评测或冻结的全数据自动调度策略。

### CEM参数化

每个样本固定原始时间格及夹爪命令，只优化一个自动选取窗口内的三个6维参考修正节点。窗口以终态平移误差最大的物体为线索，取其偏离超过阈值的起始格前30格至后15格；阈值`max(3mm,min(10mm,0.1*终态误差))`。窗口两端修正为0，中间节点线性插值，仍使用5mm/0.03rad范数上限。

两轮、每轮4候选、2精英；固定随机种子20261024。初始节点标准差平移2mm、旋转0.01rad。所有候选都通过同一IPOPT/LIBERO完整执行并记录新图像。不是单步状态重置，不在部署客户端运行CEM。该窗口策略是本项目的低成本搜索参数化，不是PhysicsGen论文原样算法。

## 完整state代价

`closed_loop_state_metrics.py`按原50ms时间戳比较完整qpos/qvel。使用MuJoCo `mj_differentiatePos`计算位姿切空间差，避免把四元数符号差当成物理误差。排除仿真时间作为代价，不使用DTW或其他时间重对齐。所有机器人及物体关节均按模型类型分组，避免将米、弧度及速度直接混加。

| 误差组 | 归一化尺度 | 权重 |
|---|---:|---:|
| 七关节位置 | 0.1rad | 1 |
| 七关节速度 | 1rad/s | 0.2 |
| 双指位置 | 5mm | 0.1 |
| 双指速度 | 0.05m/s | 0.05 |
| 物体平移/滑动关节 | 10mm | 2 |
| 物体旋转/转动关节 | 0.1rad | 0.5 |
| 物体线速度 | 0.1m/s | 0.2 |
| 物体角速度 | 1rad/s | 0.1 |

每组先取维度均方归一化误差，再乘权重；时间平均加0.25倍终态代价。尺度和权重在本轮IRLC/CEM结果产生前固定。位姿误差与控制参考偏差不混为同一指标，任务成功单独检查。加权总目标下降不意味着每个单项都单调改善。

## 实验结果

全部结果均是同一批11条诊断示范、9任务的配对比较，不是全部LIBERO的随机总体成功率。

| 项目 | 原速投影初始化 | 本轮重构 |
|---|---:|---:|
| 最终任务成功 | 10/11 | 11/11 |
| 每示范等权平均综合state代价 | 3.63846 | 1.87462 |
| 物体平移分量整体RMSE | 10.06mm | 3.19mm |
| 七关节位置分量整体RMSE | 0.07778rad | 0.07795rad |
| 七关节速度分量整体RMSE | 0.08584rad/s | 0.08033rad/s |
| 双指实际位置分量RMSE | 5.39mm | 2.33mm |
| 实际末端对源实际轨迹位置均值 | 1.85mm | 1.36mm |
| 实际末端对源实际轨迹位置p95 | 8.75mm | 5.91mm |

综合代价约下降48.5%，主要收益来自失败长任务的接触/物体轨迹恢复。关节位置几乎未改善且略有上升，不能宣称完整state每个维度都更好。此前1.66mm仅统计原10条成功样本，本表两边都包含全部11条，不做成功子集筛选。

IRLC共22次新试录后7/11示范得到接纳更新；整体成功保持10/11，平均代价仅从3.63846降到3.56241。另有更新导致成功丢失，已拒收。这说明只依赖末端误差的参考学习不足以可靠解决物体状态问题。

两个CEM探针各8次试录：

- Long00/demo_10：state代价20.39077→1.88735，任务失败→成功。tomato_sauce物体终态位置差211.17mm→4.09mm；不是靠提高末端参考跟踪精度冒充物体复现。
- Goal02/demo_1：在已接纳IRLC版本上代价3.85944→3.79716，成功保持；相对原初始化3.99321也有下降。相同采样规则也能用于已成功示范，但改善幅度较小。

本轮共38次新试录（22次IRLC＋16次CEM），加上原有11次初始化录制，每条最终轨迹均可追溯到候选历史；没有把离线搜索后的11/11当作单次控制成功率或VLA成功率。

## 数据与验证

- 最终选择及全部试录历史：`results/closed_loop_state_refined11_v1/summary.json`、`policy.json`。
- 新数据包：`data/libero_tasktol_state/20261024_closed_loop_state_refined11_v1/manifest.json`；11条成功、9任务、2110帧。前六维是物理米/弧度累积参考增量，夹爪逐帧不变，保留等待、不额外settle，缺少完整后继state的末转移仍统一裁去。
- 原始及失败候选通过`refinement_trials`链接全部保留，不以失败图像/状态冒充成功数据。新训练观测来自对应IPOPT实际执行，首帧/状态视图沿用已验证打包器对齐。
- `AGGREGATE_STATE_COMPARISON.json`记录所有组的原单位误差。
- 38个新候选均通过`analyze_state_reference.py`的源hash、关节见证FK、参考重建、原夹爪、完整物理时间、视频帧数和成功标签核验。
- 新物理指标测试覆盖四元数正负等价、单位分组、纯速度误差、时间错位；连同既有动作/参考测试共11项通过。
- 独立冷启动：`results/closed_loop_state_refined11_cold_v1/`。最终结论以该目录summary及数据包validation为准，不用录制成功代替回放结果。

## 使用入口

```text
closed_loop_state_metrics.py          物理state误差与固定代价
refine_reference_iteration.py         一次IRLC或采样参考候选的完整重录
optimize_state_reconstruction.py      全示范统一两轮更新及接纳
sample_reference_refinement.py        固定预算的低维CEM探针
merge_reference_refinements.py        合并显式试验历史，按代价接纳
build_state_reference_dataset.py --refinement ...   打包选择结果及全部试录
validate_state_dataset.py             重算接纳判据和核验数据、冷启动
```
