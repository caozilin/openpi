# 末端/物体轨迹重构与原样默认IPOPT

2026-10-24用户补充约束：机器人关节不需要跟踪原示范，默认IPOPT必须原样执行。本文件取代前一版“完整state关节跟踪”的外层目标；历史试录与数据不删除。

## 约束解释与执行边界

- 外层重构不再处罚机器人七关节位置/速度或双指关节位置/速度相对原示范的差异。
- 保留实际末端位置/方向，以及物体位姿、线速度、角速度的同时间轨迹误差。抽屉等物体的关节坐标是任务物体state，不是机器人关节跟踪。
- 原生20Hz、原夹爪命令、原始长度不变；只在开始时初始化，完整连续执行。
- IPOPT自身默认的关节运动、条件数等目标项仍完整保留。这些项不等于对原数据集关节轨迹的处罚，不得为满足外层目标而修改。
- 本轮不改`franka_mujoco/tasktol/control/ipopt`或其他共享控制器源码，不切换目标profile，不替换求解器或更改可行性验证。

## 已发现并纠正的默认参数差异

原LIBERO适配层`LiberoTaskTolSession`在未显式传入settings时，使用60次迭代、0.5秒预算；库`IpoptSettings()`真实默认是20次、0.095秒。早期结果虽然优化器源码未改，但不能称为采用库默认预算。

新录制构造原有session时显式传入未修改的`IpoptSettings()`，同时断言：

```text
session.ik.settings == IpoptSettings()
session.ik.objective_settings == ObjectiveSettings.delta_q_squared_conditioning_safeguard()
```

第二项与库`IpoptIK`不指定objective时采用的默认目标一致。没有修改优化器方法、初值处理、迭代上限或失败发布规则。实际settings、默认objective及源码hash保存到每次录制的`optimizer_default_audit.json`。机器人执行仍使用前述已维护的B10客户端；此处“默认”特指IPOPT优化器，不声称把LIBERO控制器替换为原生OSC。

## 外层目标v2

`task_pose_object_metrics.py`按原时间格计算：

- 末端位置误差（10mm尺度，权重1）。
- 末端SO(3)方向误差（0.1rad尺度，权重0.5）。
- 物体平移/滑动状态（10mm尺度，权重2）。
- 物体旋转/转动状态（0.1rad尺度，权重0.5）。
- 物体线速度（0.1m/s尺度，权重0.2）、角速度（1rad/s尺度，权重0.1）。

按组取归一化分量均方，时间平均加0.25倍终态代价。不含机械臂或夹爪关节误差。物体四元数采用MuJoCo切空间差，末端采用SO(3)对数，不进行时间重对齐。单元测试明确验证：在末端与物体轨迹保持不变时，单独改变机器人/夹爪q、dq不改变该代价。

## 本轮迁移方法与历史初始化

对前期投影、IRLC和CEM的历史候选，使用v2任务代价重新评分，仅将它们视为冻结动作候选，不以旧关节代价作新选择依据。每条选择整段可行、保持已有任务成功且v2代价最小的候选，然后在原样默认IPOPT下重新录制新图像、状态和关节输出。

旧投影初始化曾含0.01下一源state构型正则；这是历史候选生成方式，本轮没有把它带入默认IPOPT，也没有在新执行或评分中要求原关节轨迹一致。若后续继续生成新候选，禁止在外层添加原示范关节轨迹处罚；源关节数据可以用于计算末端FK或数值初值，但不能偷换为在线跟踪目标。

入口：`rerecord_default_ipopt_reference.py`。计划与结果：`results/task_pose_default_ipopt11_v1/`。真实默认执行结果必须单独验收，不把早期60次/0.5秒结果直接充当默认优化器结果。

打包器将实际solver_settings写入manifest及客户端配置；冷启动回放显式读取同一配置。旧数据缺少该字段时保留历史适配层行为，不能混入新默认数据包。验证器检查录制与回放的solver_settings一致。

## 本轮结果与验收

按上述任务代价从历史候选中重新选择后，11条示范均以库默认20次迭代、0.095秒预算重新录制成功，零拒解；覆盖9个任务，2110个原50ms动作区间。逐条动作、原夹爪、物理时间和参考重建审计全部通过。结果不是从零重新生成全部候选，也不代表对历史初始化中的构型正则作追溯删除。

按原时间戳、包含各段初始state汇总2121个状态，实际末端相对原示范的平均位置误差为1.2534mm，平均方向误差为0.0034441rad（0.1973度）。这是相对原示范实际轨迹的误差，不是相对含前馈/预载的控制目标误差。

独立新进程仅输入保存动作、初始state和参考锚点，并从数据包恢复同一默认solver_settings：11/11最终任务成功，所有动作前物理state、最终state及完整七关节参考均逐位一致。回放客户端未接收源未来state或离线关节见证。

数据包：`data/libero_tasktol_state/20261024_task_pose_default_ipopt11_v1/`。

- `manifest.json`：默认求解配置、任务目标、逐条输入与录制hash。
- `task_metric_summary.json`：末端/物体代价与实际末端误差。
- `optimizer_default_validation.json`：11次实际默认settings/objective及共享优化器/控制器源码hash一致性核验。前三次快照中的评分模块随后仅修正了导入路径；该差异显式记录，不涉及控制或代价公式。
- `validation.json`：数据包结构、观测时序、动作参考重建及冷回放验收。

冷回放证据：`results/task_pose_default_ipopt11_cold_v1/summary.json`。方法和结果仅覆盖这11条离线选择的诊断示范，不作为全部LIBERO或训练后VLA闭环成功率。
