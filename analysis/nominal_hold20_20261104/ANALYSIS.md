# 失败保持参考后的恢复机制：轨迹分析

仅离线读取17条重测和对应原始记录，没有启动任何新仿真或推理。区分连续失败段和整回合；以下32段均来自最终成功且确实经历过求解失败的10个回合。

原15条IK失败中的14条结束于IPOPT最多20次迭代，1条报局部不可行；不等同于已证明目标几何不可达。本次138个被拒帧中135个最多迭代、3个局部不可行。

13条恢复成功中10条确实经历了失败保持，另3条新轨迹没有任何求解失败。首模型动作与原组有小幅差异，不能把13条全视为该策略的因果增益。

10条经历失败而最终成功的回合共有32个失败后恢复段：最长6帧0.30秒；22段仅1–2帧。1秒是连续失败的最大容忍阈值，不是每次等待1秒。32段全部在保持期间平移误差、最大关节误差下降；平移误差段前中位9.04mm、段后中位3.95mm，最大关节误差中位0.04157rad至0.01700rad（两个中位数分别计算）。姿态误差30/32下降。

25/32段在第一次失败所在的同一个5动作块内恢复，期间没有新模型推理，因此这些恢复不能解释成模型观察后重新闭环修正。失败动作已经从队列弹出、参考增量回滚，不重试也不累加；下一帧尝试同一预测块的下一个不同动作。7/32段跨过新的模型推理边界，存在视觉闭环纠正的机会，但仅凭该边界不能证明模型输出变化是恢复的决定因素。

例：Goal task02 seed0第96–99动作失败，参考不变保持0.20秒，平移误差21.23mm至4.69mm、最大关节误差0.2382rad至0.0345rad；第100动作同一模型块内求解成功。这里同时看到跟踪追近与更换候选增量，却没有新一次模型闭环推理。

IK代码用上一接受关节命令作初值和运动参考；运行后不直接以当前实测关节位置作为每次初值。固定基座几何目标的可达性不会因为实际机械臂赶上而自动改变。跟踪改善可改变后续相机观测/接触状态、帮助后续闭环执行，但不能直接当作同一个IK问题被等候变可解的证据。失败候选不同、参考不累积是必须区分的路径变化。

反例：Spatial task04 seed2最后连续20帧失败期间，平移误差7.73mm至0.023mm、最大关节误差0.05415rad至0.000127rad，已经基本跟上保持参考，仍无法恢复并触发20帧终止。说明跟踪追近不是充分条件。

结论：直接证据确认坏增量拒绝/回滚及后续候选尝试、实际跟踪追近同时发生；其中大量段在没有新推理时已恢复。新推理后的视觉纠正可能参与跨块恢复，但尚无因果分摊。若要严格区分，需要从同一失败状态分叉：同一候选重复求解、推进队列但冻结物理、保持并推进物理、保持后强制重推理等受控比较；本次未执行额外实验。
