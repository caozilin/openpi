## 新记录格式

目录：`YYYY-MM-DD_<实验主题>/`，主文档：`README.md`，可选机器可读地址清单：`sources.json`。

每份总结至少包含：

1. **状态与更新时间**：明确运行、完成、审计或异常边界。
2. **目的与协议**：模型/数据、任务与seed、控制与成功判定、与对照组的差异。
3. **结果与结论**：分母、成功率、关键失败项；终止标签与实际因果分析分开。
4. **本地源数据地址**：绝对路径的配置、结果、统计、轨迹/视频、审计和日志；远端路径另列，未生成文件明确标记。
5. **审计与异常历史**：通过范围、未完成检查、中断/恢复和是否重测，附证据。

同一实验续跑更新原记录及本索引。文档不能代替可复核的原始数据，不保存凭据，不把大文件复制进本目录。

长期服务器操作前另须阅读项目[AGENTS.md](/media/czl/sata/franka_my_code/openpi/AGENTS.md)与[服务器使用说明](/media/czl/sata/franka_my_code/openpi/docs/TRAINING_SERVER.md)；实验记录不保存口令或私钥内容。
