# LIBERO动作重构：方法定位与复现披露

该流程可作为论文中的工程性数据适配环节，定位为“受迭代参考学习启发的离线示范重构”，不是官方LIBERO标准预处理，不声称严格复现IRLC/I2RLC或继承其收敛保证。

## 文献依据

- Salt Ducaju, Olofsson, Johansson, IROS2024, Iterative Reference Learning for Cartesian Impedance Control of Robot Manipulators：保持控制器并迭代修正笛卡尔参考。https://lup.lub.lu.se/search/publication/5dc7a6ae-c915-4d61-8803-5b37eb225b5e
- Yamane等,2026预印本, Refinement of Accelerated Demonstrations via Incremental Iterative Reference Learning Control for Fast Contact-Rich Imitation Learning：根据实测轨迹误差修正示范并用于模仿学习；其时间加速问题不同于本项目的控制器/动作语义迁移。https://arxiv.org/abs/2604.16850
- OpenVLA官方重录脚本保留成功示范并记录失败；它不验证本项目的动作重构算法，也不是严格公平对照。https://github.com/openvla/openvla/blob/main/experiments/robot/libero/regenerate_libero_dataset.py

## 当前完整流程

1. 固定来源示范顺序及原始初始状态/场景恢复规则。
2. 对原先选定来源使用已保存的B10参考初始化；补选示范按原OSC实际state相对目标语义解码，执行无关节姿态惩罚的有界FK投影。
3. 动作差分为独立累积参考增量；默认IPOPT输出完整7关节参考，经共享插值、JointReferenceTracker、Panda位置伺服与偏置补偿，在原生LIBERO中执行。
4. 对齐原始下一state与实际post-action末端，平移做差，姿态在SO(3)计算世界坐标旋转误差。
5. 5点二阶Savitzky-Golay滤波并提前1帧；增益1、0.75、0.5、0.5，平移修正范数上限20/10/10/10mm，旋转上限0.10/0.05/0.05/0.05rad。
6. 修正参考后无关节姿态惩罚地投影，再差分动作并完整rollout；关节witness只作数值初值。
7. 要求完整可行；保留已有成功，优先恢复成功；同成功类别下降低固定末端+物体轨迹代价。提前失败只有已执行前缀可测，未测后缀延用最后测得修正，必须经新的完整rollout验证。相同父参考及增益跳过重复候选。
8. 选定成功动作独立回放，完整state、关节目标及500Hz伺服样本逐位核对，保存实际pre-action双相机图像和state/action；失败只保留诊断记录。
9. 每任务收集10个不同来源示范；不足时按固定候选顺序补选。

固定条件：20Hz动作、500Hz物理，原夹爪、原速、无额外等待；容差全关闭，默认IPOPT设置和目标不改。补录沿用20261025源码快照，资产仍在原地址，不混入后续共享项目改动。

## 应披露与尚需验证

- 收集率、每轮效果、来源尝试总数、失败与补选数必须报告；筛选后的成功样本不是策略成功率。
- 区分实际末端对source实际轨迹与对补偿虚拟参考两种误差。
- 冷回放一致性是复现证明，不是随机初态鲁棒性或VLA泛化证明。
- 在训练/验证/测试分割后处理来源示范；参数调节只使用训练/验证集。未来source state只能用于离线标签，测试在线客户端不能读取。
- 若论文结论涉及策略性能，需要独立测试初态的策略闭环评估。
- 建议对比直接动作转换、仅FK投影、完整迭代重构；对比组使用同一数据选择、训练预算、评估场景和下游执行链。
- 上述滤波、上限、有限轮次和FK投影是工程选择；只提供当前采样轨迹的经验可执行性，不声称全局收敛或鲁棒可行域。

## 2026-10-31全量完成结果

40任务各10个不同来源成功示范，共400条，来源尝试430条；候选试录1930次、失败候选314次、最终未成功来源30条。已核验全部400条的双相机文件、原夹爪、20Hz对齐、默认IPOPT和共享伺服；独立回放物理状态逐位一致。全量66758执行帧相对源state末端位置均值2.2415mm、P95为10.9979mm、最大207.0207mm；旋转均值0.3428°。

成功数据中44条达到描述性离群条件：位置均值>5mm或最大值>30mm。此条件只标记，不额外筛选。最大207mm发生在Long/07 demo_15第187帧，IK末端位置残差约1e-15m，而实际末端对参考误差约199mm，属于实际执行偏离而不是IK位置约束未满足。用于论文时必须披露分布/失败并根据科学主张决定是否设置统一质量门限。

候选没有CPU超时；400条选定轨迹中20次完整IK调用墙钟超过50ms；离线等待求解再步进不能证明客户端硬实时。数据已收齐不等于已完成训练、独立策略测试或期刊所需所有实验。
